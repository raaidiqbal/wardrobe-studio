# Wardrobe Studio

Interactive clothing-rack frontend concept for an outfit assistant. The rack uses six photorealistic generated garment cutouts and a cutout of the user's navy sweater photo. Each garment hangs from a shared hanger assembly that turns toward the viewer and briefly sways when browsing or scrolling. Filters, keyboard navigation, and a temporary "today's look" selection work in the browser.

Run locally with a static server from `dist/`, for example `python -m http.server 4174 --directory dist`.

The prototype has no AI service, clothing upload, account, or saved wardrobe yet.
