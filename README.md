# Wardrobe Studio

Interactive clothing-rack frontend concept for an outfit assistant. The rack uses six photorealistic generated garment cutouts and a cutout of the user's navy sweater photo. Inspired by the user's reel reference, the garments are packed closely and hang mostly side-on until hovered, clicked, or selected with the arrows. The active garment opens forward in place, its slot widens, and the rail briefly sways. Filters, keyboard navigation, mobile horizontal scrolling, and a temporary "today's look" selection work in the browser.

Run locally with a static server from `dist/`, for example `python -m http.server 4174 --directory dist`.

The prototype has no AI service, clothing upload, account, or saved wardrobe yet.
