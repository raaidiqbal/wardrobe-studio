# Wardrobe Studio

Interactive clothing-rack frontend concept for an outfit assistant. The rack includes sample SVG garments and a user-supplied navy sweater photo. Clicking one rotates it toward the viewer; filters, keyboard navigation, and a temporary "today's look" selection work in the browser.

Run locally with a static server from `dist/`, for example `python -m http.server 4174 --directory dist`.

The prototype has no AI service, clothing upload, account, or saved wardrobe yet.
